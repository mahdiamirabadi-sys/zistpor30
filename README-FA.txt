پرسمان زیست | zistpor30
بسته ارتقا به دو حالت تمرین و آزمون

محتویات:
1) src/App.jsx
   نسخه به‌روزشده رابط کاربری. امکانات قبلی حفظ شده و حالت آزمون و گزارش آزمون اضافه شده است.

2) supabase/upgrade-exam-mode.sql
   اسکریپت ارتقای پایگاه داده و اصلاح سیاست‌های دسترسی.

3) preflight-check.sql
   بررسی فقط‌خواندنی برای اینکه مطمئن شویم جدول‌ها یا توابع آزمون از قبل ساخته نشده‌اند.

4) package.json
   نسخه فعلی package.json؛ نیازی به تغییر وابستگی‌ها نیست.

نکات مهم پیش از اجرا:
- فایل اصلی App.jsx فعلی را نگه دارید و یک نسخه پشتیبان از آن بگیرید.
- از پایگاه داده Supabase نیز Backup بگیرید.
- فایل preflight-check.sql را ابتدا در SQL Editor اجرا کنید و خروجی را بررسی کنید.
- اگر جدول یا تابعی از موارد آزمون در خروجی دیده شد، فایل upgrade-exam-mode.sql را هنوز اجرا نکنید؛ ابتدا خروجی را برای بررسی بفرستید.
- اگر خروجی preflight خالی بود، اسکریپت upgrade-exam-mode.sql را یک‌بار به‌صورت کامل در SQL Editor اجرا کنید.
- بعد از اجرای موفق SQL، فایل src/App.jsx را جایگزین src/App.jsx فعلی پروژه کنید.
- package.json را تغییر ندهید.
- فایل supabase.js و فایل .env فعلی پروژه را حفظ کنید؛ آن‌ها را حذف یا با فایل دیگری جایگزین نکنید.
- هیچ کلید service_role یا secret را در کد مرورگر قرار ندهید.

ترتیب پیشنهادی:
1) Backup
2) اجرای preflight-check.sql و بررسی خروجی
3) اجرای upgrade-exam-mode.sql پس از تأیید
4) جایگزینی src/App.jsx
5) اجرای npm run build
6) آزمایش با یک حساب دبیر و یک حساب دانش‌آموز

رفتار نسخه جدید:
- تمرین: نتیجه هر پاسخ بلافاصله نمایش داده می‌شود.
- آزمون: پاسخ‌ها تا پایان مخفی می‌مانند و کارنامه از سرور دریافت می‌شود.
- شروع تمرین، هر آزمون ناتمام قبلی همان دانش‌آموز را لغو می‌کند.
- شروع آزمون جدید، جلسه ناتمام قبلی را لغو می‌کند.
- سوابق تمرین قبلی در جدول attempts حفظ می‌شود.
- گزارش آزمون در جدول exam_sessions ذخیره می‌شود.
